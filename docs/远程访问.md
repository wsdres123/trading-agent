# 远程访问配置（多电脑登录）

系统已支持多用户登录：用户名密码 + Redis 会话（7 天有效）+ 分组按用户隔离。
本文档说明如何让**其他电脑/手机**安全地连进来——用 [Tailscale](https://tailscale.com) 组私有网络（免费、自带加密、无需域名备案、不暴露公网）。

## 一、这台服务器（一次性）

```bash
# 1. 安装 Tailscale（需要 sudo）
curl -fsSL https://tailscale.com/install.sh | sh

# 2. 登录（首次会打印一个 URL，浏览器打开授权你的 Tailscale 账号）
sudo tailscale up

# 3. 确认拿到 100.x.y.z 地址
tailscale ip -4

# 4. 重启服务（run.sh/start.sh 会自动检测 Tailscale 并绑定到 100.x.y.z）
bash stop.sh && bash run.sh
```

## 二、其他电脑/手机（每台一次性）

1. 访问 https://tailscale.com/download 安装 Tailscale 客户端，**用同一个账号登录**。
2. 浏览器打开：`http://<服务器tailscale IP>:8601`（IP 用 `tailscale ip -4` 查到，形如 100.x.y.z）。
3. 首次打开会看到登录页，输入用户名密码。

> 服务器没有安装 Tailscale 时，脚本自动退回 127.0.0.1 只允许本机访问——安全兜底，不会裸奔。

## 三、用户管理

```bash
cd /home/lixiang/langchain/bigA/trading-agent_new

python -m src.auth register 张三            # 交互式设置密码
python -m src.auth register 李四 -p 密码123456
python -m src.auth list                     # 查看所有用户（第一个用户是 admin）
python -m src.auth passwd 张三              # 改密码
python -m src.auth rm 李四                  # 删除用户
```

首次打开网页且系统无任何用户时，页面会直接提供"创建管理员"表单，也可以在网页上完成第一个账号。

## 四、安全特性说明

| 项 | 实现 |
|---|---|
| 密码存储 | bcrypt 哈希（12 轮），.data/users.db |
| 会话 | 32 字节随机 token，存 Redis，TTL 7 天滑动续期 |
| 防爆破 | 同一用户名连续失败 5 次锁定 15 分钟 |
| 数据隔离 | 每个用户只能看到/编辑自己的分组 |
| 网络 | 仅 Tailscale 内网可达（100.x.y.z），不对公网暴露；Tailscale 自带 WireGuard 加密 |

## 五、已知限制

1. **会话 token 在 URL 里**（`?token=xxx`）：Streamlit 1.30 没有 cookie 写入 API。仅限 Tailscale 内网使用是安全的；若将来要公网开放，先升级 Streamlit（≥1.37）改 cookie，或直接前置 Nginx 登录。
2. **行情数据是所有用户共享的**（Redis 缓存），只有分组/自选按用户隔离。
3. 服务器重启后，Tailscale 需设为开机自启：`sudo systemctl enable --now tailscaled`。
4. 忘记 admin 密码：`python -m src.auth passwd admin` 重置。

## 六、以后想对公网开放怎么办

Tailscale 方案适合"我 + 少数熟人"。要对任意用户开放需要：域名 + HTTPS + ICP 备案（大陆）+ Nginx 反代 + 短信/微信登录（微信需企业主体）。那是另一个量级的工程，届时再评估。
