情绪节点

混沌分为混沌和混沌分歧
混沌
特征：
指数震荡或者小阴小阳，，题材混乱，无主线，但是市场没有明显的亏钱效应，市场大面数，市场没有明显的赚钱效应，这种周期一般是在B，D周期比较多
标准：
中级周期在A，B，D周期
一般平均股价显示转或者空
跌幅超过-7%的30个以内
跌停数目小于5
平均股价涨跌幅在1%以内


混沌分歧
特质：指数震荡或者小阴小阳，一般平均股价显示转或者空，题材混乱，无主线，市场亏钱效应明显，大面数多,尤其热门股不能批量跌停
标准：
中级周期在A，B，D周期
一般平均股价显示转或者空
跌幅超过-7%的30个以上，50个以内
跌停数目小于5
平均股价涨跌幅在1%以内
同花顺热门股跌超1%
打板大面数大于5

主升
主升分为主升确认，主升加速，主升高潮，主升分歧，主升分歧转一致，主升修复，主升延续

主升确认
特征：一般出现在修复节点后面，指数要起势，低位驻底，或者高位突破，或者突破箱体，市场亏钱效应很弱，主线出现，跟随指数共振上涨，连板空间打开，赚钱效应变好，市场高度个股变多

标准：
中级周期在A，B，C周期
A C周期需要有主线，B周期可以无主线
一般平均股价显示转或者多
跌幅大于-7%的一般少于20个
热门股无跌停
连板空间突破5板以上
打板大面数低于8个
同花顺热股指数涨超2%
指数涨幅小于1%



主升加速
特征：一般在主升确认后，核心个股，热门个股大多高开，或者一字板无法买入，核心个股缩量加速

标准：
中级周期在A，B，C周期
一般平均股价显示转或者多
连板天梯高位股缩量加速
跌幅大于-7%的一般少于20个
热门股无跌停
连板空间大于5板

主升高潮
特征：可能跟主升加速或者主升确认合并，看这波主升的强度，基本主线核心加速，主线板块内补涨个股大多涨停，板块指数跳空大涨。

标准：
中级周期在A，B，C周期
一般平均股价显示转或者多
平均股价涨超2%
指数比较昨日放量2千亿以上
指数涨超1%
跌幅大于-7%的一般少于15个
连板空间大于6板

主升分化
特征：指数震荡，一般发生在主升高潮后
标准：
跌幅大于-7%的一般大于5个小于20个
平均股价涨幅小于1%




主升分歧
特征：一般平均股价显示转，一般发生在主升高潮的次日，持续时间可能是1-2天，一般指主线首次分歧

标准：
中级周期在A，B，C周期
一般平均股价显示转
跌幅大于-7%的一般大于20个


主升分歧转一致
特征：一般平均股价显示转，热门核心股没有出现亏钱效应，但是后排个股可能会出现亏钱效应，也指的是主线第一次分歧，可能力度比较小，当天上午分歧，下午就分歧转一致了，因为主线的韧性很强，这种发生的概率很高

标准：
中级周期在A，B，C周期
一般平均股价显示转或者多
跌幅大于-7%的一般大于20个
同花顺热股指数，日内低开高走或者V型反转
热门股没有大跌



主升修复
特征：一般平均股价显示多，一般在主升首次分歧后，情绪修复，核心个股反包，赚钱效应修复，延续修复
标准：
中级周期在A，B，C周期
一般平均股价显示多
同花顺热股指数涨超1%

跌幅大于-7%的一般少于20个


主升延续
特征：一般平均股价显示转或者多，主升末期，主线可能已经分歧俩次了，这阶段，核心龙头个股基本走弱，补涨个股开始加速




退潮
退潮分为退潮，退潮加速，退潮转衰竭，冰点

退潮
特征：一般平均股价显示转或者空，指数一般震荡或者大跌，大面数增加，热门个股出现跌停，龙头个股断板或者大分歧，这个阶段只能空仓规避，大面数是相对的与昨天比较的
标准：
中级周期在A，B，D周期
一般平均股价显示转，空
市场个股跌幅大于-7%的大于50个
热门股出现3个以上跌停
热股指数跌超1%
连板空间降低



退潮加速
特征：一般平均股价显示空，大多热门个股一字跌停，连续跌停，，并且存在一字缩量跌停

标准：
中级周期在B，D周期
一般平均股价显示转，空
市场个股跌幅大于-7%的大于100个
热门股出现5个以上跌停
总跌停数大于10



冰点，
特征：一般平均股价显示空，可能和退潮加速重合，一般伴随指数大跌，情绪和指数共振退潮，

标准：
中级周期在B，D周期
一般平均股价显示空
跌停数20个以上
市场个股跌幅大于-7%大于200个
指数跌幅大于1%
热股指数跌超3%



退潮加速转衰竭
特征：一般退潮期第3天，跌停数减少，跌停数减少到10个以下，或者一字跌停的空头龙被反核开板
标准：
中级周期在B，D周期
一般平均股价显示空
跌停数减少到10个以下
市场个股跌幅大于-7%小于80个

修复
修复分为若弱修复，中等修复，强修复

弱修复
特征：指数缩量震荡，大面数有所减少，但是亏钱效应还存在，市场量能不足，体现在修复不完全，修复都是相对的，比如前天大面数200个，今天50个这种也算弱修复，修复50%以下叫弱修复
标准：
中级周期在A，B，D周期
一般平均股价显示转，空
比昨日大面数修复超50%，低于70%



中等修复
特征：一般平均估计显示转或者多或者空，指数微放量或者缩量，大面数大幅减少，核心个股修复，主线修复，修复大面数达70%

标准：
中级周期在A，B，D周期
一般平均股价显示转，空，多都可能
跌幅大于-7%，小于20
比昨日大面数修复超大于70%
热股指数涨超1%
打板大面数少于10个


强修复
特征：指数放量大阳，一般平均估计显示转或者多，大面数消失,核心个股反包，赚钱效应加强



标准：
中级周期在A，B，C周期
一般平均股价显示转，多
跌幅大于-7%，小于10
修复大面数90%以上，比如昨天100个大面，今天就10个以内
打板大面要少于5个
指数比昨天放量1000亿以上
平均股价涨超2%
